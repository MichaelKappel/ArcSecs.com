# ArcSecs Part XXIX — curated integration

## Executive direction
Advance one physical matter-regulator theory with impedance-matched EM, strictly positive photon mass, causal history-dependent energy exchange, material recession and physical clocks. Establish the source of the local emission ceiling before deriving aging and astronomical observables. No complete parameter set has yet been demonstrated. The current working paper remains the full review through XXVIII plus this Part XXIX research integration; these six documents are source-grounded working addenda.

## Reports and interfaces
- [C-01 — Cosmic mass, inertia and emission ceiling](01_curated_report.md): Derive a common matter-regulator action, screen local bodies in 3D, derive measured clock/cavity responses, and enforce causal characteristics with no per-ray speed clamping. Compare fixed ceiling and physically varying domain boundary tests.
- [Positive-mass photons — causal emission, aging and energy ledger](02_curated_report.md): Implement the joint photon–reservoir–matter PDE from one action or explicitly conservative open-system equations. Verify positive energy, momentum, mass-gap emission and phase/pulse transport separately. Then fit the subdominant loss channel with actual timing data.
- [Constant time — physical clocks, inherited motion, and causal reach](03_curated_report.md): Derive physical clock Hamiltonians and common observable transformation rules; use signed moving endpoints and a retarded domain field. Test clock ratios, decay, GPS, and the arrival-time/redshift relation without using arbitrary clock rescaling.
- [Astronomical distances — transport, anchors and extreme objects](04_curated_report.md): Run actual rays from fixed and moving sources to a calibrated receiver; derive both optical Jacobi maps and flux plus pulse transfer. Fit anchors first, then high-z jointly; report each extreme object’s estimator and uncertainty.
- [Relational gravity — capture, inertia and dark-sector accounting](05_curated_report.md): Specify nonlinear interaction and regulator coupling; derive PPN/clock/deflection and conserved tensor modes, run merger lensing and dark-reservoir phase-space tests. Quantify only independently supported energy inventories.
- [Physical cosmic bubbles — domains, observational search and integration](06_curated_report.md): Combine the upstream modules using one physical domain action and parameter ledger; build injection/recovery pipeline on public maps only after deriving signal templates; preserve no-detection outcomes and historical age constraints.

## Integration acceptance gate
One parameterized action or energy-accounted coupled system; stable causal characteristics; nonzero mass and consistent emission; clock and matter response; monotonic trajectory check; joint spectral/temporal/optical observables; independent anchors; physical reservoir ledger; controlled bubble search. No numerical fit or observed discovery is claimed in this curation.
