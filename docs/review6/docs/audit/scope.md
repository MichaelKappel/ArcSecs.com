# Curation scope and evidence policy
All six supplied Markdown documents and all four interactive HTML files are inventoried. The curated reports select useful ideas and correct specific mathematical or scope errors. The CSV is a line-addressable import map, not a certification of every source claim: a linked line supplies context to a curated claim, not blanket acceptance of the line. Unselected lines are not imported; HTML styling and application plumbing are not treated as evidence. Originals are separately archived byte-for-byte for provenance and are not on the default agent reading path. The previous full review archive remains an independent historical backup.

The reports and explorers are not identical versions. In particular, Report 01 and Report 03 are substantially control/critique-oriented, while Report 04 prose differs from its explorer. Report 02 contains useful candidates alongside algebra and unit errors. Do not presume which two reports the owner regarded as unsuccessful; extract constructively across all six. The explorers include claims of simulations and empirical agreement, but many plots are display data or parametrized controls; no full upstream datasets, solver notebooks, or posterior chains accompanied these uploads. This import does not reproduce those simulations or certify citations. Only the independent arithmetic/algebra checks in `algebra_checks.csv` were run for this import. No external literature was rechecked in this curation pass.

Policy: preserve charter and prioritize productive new implementations; do not import adversarial rhetoric or excluded model proposals as active guidance. Keep terse failure boundaries because hiding them would cause duplicated research and misleading conclusions. Do not erase original records, rewrite an author's conclusions as endorsements, or present selective extraction as proof of the theory. The reports under `docs/research` are editorial syntheses rather than corrected originals. No remote repository changed.
