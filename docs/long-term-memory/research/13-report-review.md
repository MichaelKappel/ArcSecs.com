# Editorial Review — Thirteen New ArcSecs Manuscripts (23 November 2026)

## What was done

Each of 6,246 source lines from the 13 uploaded Markdown reports was indexed and classified by machine-assisted editorial rules as a heading, observation/data, proposed mechanism, causal interpretation, mixed observation/inference, citation/asset, or other. Targeted interpretive wording was corrected while preserving reported measurements and the full technical bodies. 68 embedded image data references were extracted into independently hashed PNG assets so documents are export-friendlier. All originals remain external to the *new* active archive; the revised active manuscripts are R25–R37.

**Limit of this review:** Line indexing is not proof of manual scientific verification of every sentence. The review is a substantive editorial separation of observed results from causal conclusions; primary-source checks are documented separately. Reported numerical fits and experiments remain claims requiring data/code audits before journal submission.

## Source accuracy requirements

Neither deleting contrary measurements nor asserting an unresolved mechanism as an observation would meet scientific publication requirements. The goal is to **change the interpretive conclusion only when the data allow it**, keep the measured data, and design new empirical discriminants. The previously verified primary-source anchors are collected in [measurement-vs-inference](measurement-vs-inference.md).
