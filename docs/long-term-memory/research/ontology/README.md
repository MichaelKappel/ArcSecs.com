# R38 Typed Ontology — Export-Safe Implementation Aids

This folder extracts the 18 types from [R38](../../reports/R38.md) into machine-readable *specifications* and makes no claim of an executed physical model.

- `entity_schema.json`: exact 18 identifier and name pairs with type categories and epistemic guardrails.
- `types.csv`: convenient reference for prompts, schemas, and AI memory.
- Measurements and citations are retained in R38; original author submission remains `docs/long-term-memory/sources/R38_original.md`.
- The type system does **not** constitute evidence that photon invariant rest mass, cosmic light slowdown, external bubble pull, or universal T has been independently detected.
- A later runtime validator must be developed to enforce any object-graph or conservation invariant; present checks only validate this metadata file.
