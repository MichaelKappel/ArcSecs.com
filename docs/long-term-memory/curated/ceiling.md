## C01-02 — Finite-range causal collective inertia
**Status:** candidate.  **Input:** C01-M L23–27; C01-H L699–710.

Use (C_I^(-2) d_T^2 - Laplacian + lambda^(-2)) I=g rho_src with retarded conditions and specified physical sources. Its static Yukawa Green function is a useful boundary control. C_I is a distinct characteristic. Test inertia as an independent response M_0(I)=m_*(C_*/C)^p (p=1 or 2 in the supplied model); the corresponding local particle Lagrangian is -M_0 C^2 sqrt(1-v^2/C^2) for |v|<C. Do not equate this ansatz to proven mechanical inertia or use an instantaneous kernel for evolving matter.

## C01-03 — Shell and void response
**Status:** conditional analytic.  **Input:** C01-H L741–742; C01-H L699–708.

For a static thin shell of mass M and radius R with q=R/lambda, I(0)=g M exp(-q)/(4 pi R). Interior ratio I(r)/I(0)=sinh(q r/R)/(q r/R); exterior ratio sinh(q)/q * exp[-q(r/R-1)]/(r/R). A finite nonzero interior regulator can coexist with zero Newtonian shell force; a finite-range regulator can have an interior gradient. In a uniform reference density the void-center fractional removed response is 1-(1+s)exp(-s), s=b/lambda. These results were independently checked in book 30R, not a detection of a wall. For irregular shells use zero-padded/open-boundary convolution with independent spherical and resolution checks; the explorer reports FFT results but supplies no underlying solver run record.

## C01-04 — Separate characteristic, group and causal speeds
**Status:** analytic and test gate.  **Input:** C01-H L134–136; C01-H L589–591; C01-H L727–733; C01-H L740–748.

For omega^2=C^2 k^2+Omega^2 with Omega>0, v_g=C sqrt(1-Omega^2/omega^2), v_phase=omega/k, C_front=C; a finite-frequency group packet is strictly below the characteristic. C_causal is the largest relevant characteristic of coupled sectors, not a synonym for the electromagnetic front. A static profile conserves coordinate frequency; increasing C at fixed Omega increases group speed. Keep the local ceiling and the age-dependent transport mechanism distinct. Check local clock ratios, anisotropy, Cassini and multimessenger lags; these constrain couplings, not a declaration about physical time. Chapter 30Q demonstrates that matched local polarization dispersion does not imply matched boundary transmission.
