# Integrated edition reading formats

All formats derive from `book.md` with UTF-8-safe metadata. The PDF uses XeLaTeX; EPUB 3 embeds MathML and manuscript figures; Word uses editable Office Math. E-reader and office math rendering varies. Use PDF for exact mathematical layout and Markdown for the canonical source. The earlier source and legacy figures remain in the prior archive. Run the build and publication checker from the project root after edits.
