## Install
Back up and stage first. Appearance → Themes → Add New → Upload Theme → select ArcSecs-Theme-v3.138.0-Open-Knowledge.zip → replace arcsecs-v5. Save Settings → Permalinks and clear caches if routes do not resolve. The archive is large: a hosting file manager or adjusted WordPress/PHP upload limit may be necessary. The scientific physics engine plugin is unchanged.

Test /publications/, /read-book/, /read-scientific-paper/, /llms.txt and /arcsecs-sitemap.xml while logged out. Test original PDF/EPUB, Markdown, publication manifest JSON, figures, links and mobile layout. The main-book reader links the separately appended Review 6.0; the print PDF includes both. Existing Customizer URL overrides remain supported. The Markdown book derivative removes one internal editorial instruction comment, preserving all scientific prose; the paper Markdown and both original PDFs plus EPUB remain identical. HTML uses Pandoc MathML and browser PNG derivatives of paper figures; use canonical PDFs/Markdown for exact scientific notation and print pagination. Three book references are pinned to GitHub and may require login until made public. No DOI is invented.

The theme assets are public files when served; robots.txt is not a privacy or access-control system. Keep staging behind authentication; don't put private archives in the web root. The virtual robots policy preserves host/plugin directives and WordPress indexing preferences. The public-root static files are optional examples for production only; existing root robots.txt, HTTP headers, WAF and CDN policies can supersede the theme. Review live crawler access rather than assuming capture or training inclusion.
