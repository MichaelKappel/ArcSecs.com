BeyondSpacetime.org v2.2.1 — deployment and acceptance

1. Back up the complete live document root. Extract the cumulative Quality-Hardening Add-On into the existing root. It contains module-level .htaccess files; merge if customized. The root homepage, original root configuration, root favicon, robots.txt and sitemap are NOT included. The original v1.2.0 source is still unavailable. Use the standalone archive only for a new empty staging root.
2. PHP 8.1+ 64-bit required; tested PHP 8.4.24 with Apache 2.4.68. Apache must permit directory-level AuthConfig, FileInfo, Options and LimitRequestBody directives (AllowOverride All or equivalent explicit allowances). Enable mod_headers and mod_mime. If your host disallows any directives, ask the administrator to implement equivalent rules; do not simply remove access protections. Ensure _lib and hidden files are denied, path suffixes rejected, directory listings and MultiViews disabled, and display_errors off. Nginx/IIS need equivalent server configuration; the Apache directives are not automatically enforced there. Ensure HTTPS and an appropriate rate-limit/body-size policy. Do not set all files to 0777.
3. Verify 200 /museum/, /foundations/, /evidence/, /research/, /model-comparison/, /timeline/, /global/, /visualizations/, /knowledge-graph/, /offline/. Verify 403/404 for /museum/.htaccess, /museum/_lib/site.php and /museum/index.php/unexpected. Verify 200 /timeline/compare/ with the chooser; invalid pair 400. Check graph JSON-LD/CSV MIME and API JSON responses. Check 404 for absent routes. Existing legacy navigation is shown if app/models.php and app/render.php exist (or private museum/_lib/legacy-root.enabled is present). Only set this marker if the legacy routes really exist.
4. In /offline/, use Check update, then Apply update if offered. The offline cache version changes to bsp-offline-2.2.1, and saved notebook recipes/progress are untouched. Verify initial preparation, failed connection retry, installation and close/reopen offline on HTTPS, including mobile Safari/Chrome as applicable. No actual PWA installation was tested here.
5. Verify original ArcSecs links and existing root simulations, featured YouTube playback after user activation, keyboard navigation, screen readers, contrast, CSP and security headers on production. Use Search Console for live indexing, not local sitemap tests. Submit /museum/sitemap-index.xml as appropriate. Restore backup if integration fails.
