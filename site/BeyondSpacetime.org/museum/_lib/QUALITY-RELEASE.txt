BeyondSpacetime.org v2.2.1 — Quality, Reliability & Deployment Hardening
Scope: supplied v2.2.0 recoverable standalone and cumulative packages; no production changes.

Findings and corrective actions
HIGH — Apache served .htaccess as an ordinary file in the baseline staging configuration. Deny dotfiles in the ten supplied module roots and standalone root. Existing _lib denial retained and exhaustively tested. Configuration exposure is not evidence of a secret leak.
MEDIUM — PATH_INFO aliases (e.g. unexpected suffix after index.php) served duplicate museum pages. Set AcceptPathInfo Off; disable MultiViews and directory listings. Verified genuine 404 under Apache.
MEDIUM — 261 of 354 standalone archive members had mode 0600. A different web-server account could fail to read those files after extraction. Normalize all ZIP regular file modes to 0644; private HTTP access still depends on server restrictions. No writable-to-all files.
MEDIUM — Standalone navigation had 30 distinct missing legacy destinations. Detect the original v1.2.0 app source before displaying legacy links. Keep them on existing legacy installations; add current research and comparison links to foundation pages. For a customized original root, hosting administrator may create a private museum/_lib/legacy-root.enabled marker after verifying those routes. No fake replacements or redirects for missing simulations.
MEDIUM — Initial PWA install could wait forever on navigator.serviceWorker.ready when install failed. Replace indefinite wait with bounded 20-second activation check, retry availability and deduplicated watch registration. Update service-worker cache identity to bsp-offline-2.2.1 so revised UI is staged. Verified in simulated lifecycle/setup tests only; actual secure-origin registration and airplane-mode restart remain pending.
MEDIUM — Static offline page lacked CSP in tested baseline, static headers were inconsistent. Add CSP scoped to offline/index.html and uniform no-sniff, referrer, frame, and permissions headers at module level, avoiding duplicate headers with Apache mod_headers. Preserve opt-in YouTube frame exception solely on museum homepage. No new remote dependencies.
MEDIUM — Foundation and global APIs accepted a media-type lookalike beginning with application/json. Require exact media type followed only by optional parameters. Preserve existing error status conventions. Set Apache module transport cap to 256 KiB (allows URL-encoded forms); existing 32/64 KiB API parser limits remain. Rate limiting and public load protection belong at hosting level.
LOW — GET-only museum, graph and visualization APIs gave non-JSON 405 responses. Normalize to JSON error, no-store, Allow and noindex headers. Reject control characters in museum search. Mark all submitted foundation, evidence and global calculation pages no-store.
LOW — Empty timeline compare link returned 400. Render an accessible selection form for an empty request; explicit invalid pairs still return 400.

Scientific audit: no solver equations, original scientific catalogs, semantic graph data, or archived source fingerprints changed. All 15 existing model implementations exercised at 64 deterministic configurations per model (bounds, midpoint, seeded samples). Validate finite rectangular ordered samples and independent physical identities. Cross-check escape population solution against RK4 integration at seven ratios, including 3.999999, 4, 4.000001, and flat matter+Lambda age against Simpson integration. These are implementation checks, not observational or theoretical validation. Numerical residuals are retained. Source documents were not re-reviewed independently this round.

Verified environment: Apache 2.4.68 + PHP 8.4.24, mod_headers, standard local HTTP; no external services. 18 regression suites passed, 4,383 checks. New independent scientific checks: 1,930. PWA activation unit checks: 4. See TEST-RESULTS.txt for transport/security, crawl and browser results. The crawl is standalone only (172 canonical pages, 442 distinct internal URL targets and 350 fragment references); external links were not checked. Baseline and final local response timings are not production performance metrics. Browser harness inlined actual PHP responses and local assets, because direct navigation is blocked. This does not verify live CSP enforcement in a browser or actual PWA install. No full WCAG, vulnerability certification, penetration/load test, TLS or production hosting validation claimed.

Release decision: local QA passed; production acceptance still required. Recommended cumulative upgrade for existing complete website. Standalone is a staging/new-install recoverable edition and does not restore missing original homepage, WebGL scenes or 13 legacy laboratories. Do not overwrite the original root. Preserve existing root .htaccess, homepage, favicon, robots and sitemap. The standalone root configuration is only for a new root. APIs and catalogs retain their component/schema versions; package version is 2.2.1.
