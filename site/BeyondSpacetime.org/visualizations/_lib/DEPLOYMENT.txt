BeyondSpacetime.org v2.1.0 — Advanced Interactive Scientific Visualizations

RECOMMENDED: cumulative integration add-on. Back up the current document root and extract the ZIP contents directly into it. This release adds /visualizations/ and updates the museum catalog, sitemap index, navigation, and six module presentation templates. It does not overwrite root files, the original homepage, earlier immersive scenes, favicon, or original video. Existing legacy navigation can be updated with a link to /visualizations/ (Visualize). All existing scientific calculation sources and offline resources are unchanged. The v1.2.0 root archive is still unavailable.

STANDALONE RECOVERABLE MODULES: for an EMPTY document root or staging only. The standalone ZIP adds the existing v2.0.0 root redirect, 404 helper, favicon, robots.txt, llms.txt and updated sitemap. It does not restore the unavailable original v1.2.0 labs, atlas, WebGL scenes or root site. Protect staging with authentication to prevent indexing. Do not use as a replacement for a complete production installation.

Requirements: PHP 8.1+ 64-bit, HTTPS, Apache directory indexes and access rules (or equivalent host configuration). Deny access to every module's /_lib/ directory and hidden files; disable directory listings. Production uses only native PHP, HTML, CSS, JS and SVG. Python and Node are development test/build tools only. Original optional YouTube embed remains click-to-load.

New gallery: /visualizations/; nine exhibit URLs: photon, clocks, separation, cosmic-domains, cosmic-age, escape, wall, distance, anchors. Each has shared-scale candidate/reference curves, synchronized sample diagram, selected-form metrics and parameter editing. GET form parameters use p[key]. Only photon, clocks and escape support opt-in time playback. Other scenes are parameter sweeps, not time evolution. The diagrams are not physical observations. No new dynamical gravity, bubble wall or cosmological expansion solver is claimed. Exact form metrics are independent of the nearest sampled sweep value. References hold all parameters fixed except displayed overrides; coincident curves can overlap. The photon path integrates the original speed samples; the escape bars are a population ledger, not individual photon trajectories. Numeric output retains raw floating-point residuals. No new empirical validation.

Machine API: GET /visualizations/api/?scene=photon&p[gap]=0 (URL encode brackets as needed). Returns original candidate/reference numerical results, parameter overrides, common plot domain, initial sample and source solver SHA-256. Invalid inputs return HTTP 400. Read-only endpoint; POST rejected. /visualizations/catalog.json and /visualizations/sitemap.xml are static machine discovery resources. Research and AG-UI endpoints remain unchanged. No external AI or analytics provider.

Local tests (from root): php -S 127.0.0.1:8161 museum/_lib/dev-router.php ; in a separate terminal: python3 visualizations/_lib/test.py http://127.0.0.1:8161 ; node visualizations/_lib/geometry-test.js ; python3 museum/_lib/test.py http://127.0.0.1:8161.
