BeyondSpacetime.org v1.5.0 — Advanced AG-UI Research Workspace

INSTALLATION
Recommended cumulative package: BeyondSpacetime.org-v1.5.0-Cumulative-Add-On.zip. It contains the unmodified 80 files of v1.4.0 Foundations + Evidence plus the new research/ module. This is NOT a full replacement for the v1.2.0 website. That root archive was unavailable. Existing root homepage, video, theme, favicon, navigation, and original simulations are not included or overwritten. The research-only package requires foundations/ and evidence/ from v1.4.0 already installed. Back up the document root and any customizations before extraction. Do not retain the ZIP in public hosting.

Extract the cumulative package directly into the existing site root. PHP 8.1+ with JSON, no database, framework, remote model or runtime libraries. The exact previous model files are loaded server-side by the new workspace. The new section uses existing evidence/assets/compass.png and banner.webp. Existing root rewrite rules must pass through real directories and files. Apache 2.4 needs DirectoryIndex index.php, Options -Indexes, and Require all denied within the three _lib directories. Verify those rules are enabled. For Nginx or a custom server, explicitly deny requests to /research/_lib/, /foundations/_lib/, /evidence/_lib/ and route actual directory index.php files via your existing PHP configuration. Never expose PHP source or tests. Configure HTTPS, resource/body limits and rate limiting at your hosting layer; the new JSON API checks 64 KiB input and a maximum of eight cases. Keep PHP errors private and logs outside the document root. Do not run the development server on the public internet.

INTEGRATION
Add Research Workspace → /research/ to the existing root navigation (app/render.php in earlier releases). Add links from the homepage, /agents/, /foundations/ and /evidence/ as desired. The existing site navigation and sitemap were not automatically changed. Submit the additional /research/sitemap.xml separately; optionally reference it in your existing robots.txt. Preserve the earlier foundation and evidence sitemaps. All three new public routes have server-rendered content, canonical URLs, page metadata and structured breadcrumbs. Query presets and POST results are noindex; the JSON catalog remains readable. No guarantee of indexing or model training.

ACCEPTANCE CHECKLIST
- /research/ opens the editor, /research/presets/ offers five ready-to-run recipes, /research/protocol/ documents the API.
- /research/catalog.json lists 15 existing models, 26 evidence records and seven gates. GET /research/api/ supplies the live catalog. POST /research/api/ with JSON {"plan": ...} runs a recipe. The plan schema is beyondspacetime.research-plan.v1; use a preset plan from the catalog. Cases ordered, 1–8; numeric bounds strict; first case of each model is its reference. Optional expected_sha256 replays against a previous digest. Cross-model calculations remain independent, no common fitted parameters or combined likelihood.
- AG-UI-shaped request {"threadId":"demo","runId":"r1","messages":[],"state":{"plan": ...}} emits RUN_STARTED, matching STEP_STARTED/STEP_FINISHED per case, text message events, STATE_SNAPSHOT and RUN_FINISHED, or RUN_ERROR on unexpected execution failure. Invalid input is rejected before streaming. No arbitrary tools, external AI service, conversational reasoning, persistent session, protocol resume or certified SDK interoperability. Proxy buffering may delay events. Client cancellation cancels display, not necessarily PHP computation.
- Run the escape preset; inspect three cases and two comparisons. Export JSON, metrics CSV and sample CSV. Import the result and rerun; on the same PHP version and same calculation/data files, the result hash should match. Imports trust only the recipe and optional expected digest; all numerical results are recomputed. A digest does not authenticate a scientist, prove physical validity, or substitute for observations. The result hash includes the PHP version, serialize_precision and file digests. Plots have individual axes; use metric deltas for direct comparison.
- No-JavaScript form accepts an editable JSON recipe and returns results or a downloadable JSON bundle. All scientific conclusions remain conditional, and evidence status and gate acceptance criteria are preserved. The workspace does not mark gates passed. No new scientific empirical claims.
- Verify /research/_lib/model.php, /evidence/_lib/ledger.json, /foundations/_lib/lessons.json return 403/404; unknown paths return 404. Test live links and production routing, host CSP, SSE delivery, accessibility and load/security settings. No new external dependency or private .uai material is included. The app does not save requests or results; hosting may log requests.
