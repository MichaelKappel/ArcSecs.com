BeyondSpacetime.org v2.3.0 — Scientific Experiment Design Studio

INSTALLATION
Use the cumulative experiment-design upgrade on the existing document root after backing up the full site. It includes all recoverable v2.2.1 modules plus experiment-design, regenerated museum and knowledge graph catalogs, and updated navigation. No original legacy root files are overwritten. The original v1.2.0 website source is still unavailable. The separate standalone package is a recoverable staging/new installation only; it does not restore the old root WebGL scenes or laboratories.
PHP 8.1+ 64-bit, Apache 2.4 with mod_headers, mod_mime and the existing module-level .htaccess permissions; tested locally on PHP 8.4.24 and Apache 2.4.68. Preserve prior security rules. For Nginx, implement equivalent _lib/hidden-file denial, no directory indexes, no PATH_INFO, request ceilings and headers. Enable HTTPS and hosting-level rate limits. Do not make all files writable. Production runtime needs no database, Node, Python, external AI or JavaScript framework.

VERIFY
1. Open /experiment-design/ and select a worked protocol. Inspect all four cases, criteria and bounds. Seal without executing. Save the seal JSON; use Execute sealed protocol. Verify result, control outcomes, chart and downloads. A changed protocol or runtime requires explicit resealing; a hash is not a trusted timestamp.
2. Open /experiment-design/replay/ and import a saved protocol or result. The importer strips numerical results and recomputes the sealed recipe. Direct text/API input capped at 64 KiB; file picker supports up to 1 MiB before extracting recipe. Old seals generated on a different installed solver/PHP configuration may be rejected; this is intentional, not a claim of cross-runtime reproducibility.
3. Check /experiment-design/method/, /experiment-design/catalog.json, /experiment-design/openapi.json, /experiment-design/api/ (GET catalog; POST seal/run JSON). Review /museum/search/?kind=design and /knowledge-graph/?kind=design. The graph was rebuilt from exact catalog fields; no inferred evidence relationships. The old research AG-UI endpoint is preserved; new design API uses JSON.
4. Verify 403/404 for /experiment-design/.htaccess, /experiment-design/_lib/model.php, /experiment-design/index.php/unexpected. Check no-store and frame-src none for protocol pages and API. API JSON input cap 64 KiB; Apache transport cap 256 KiB. No application-level storage; hosting logs may exist.
5. Submit /museum/sitemap-index.xml as appropriate (174 canonical pages). Add a Design menu link to the original root navigation. Standalone has root redirect and updated root sitemap/llms.txt. Cumulative archive deliberately leaves original root sitemap/robots/favicon/home/config untouched.
6. Retest live original simulations, ArcSecs publication links, YouTube playback, PWA installation/offline reopening, HTTPS, browser CSP, accessibility and production performance. These remain unverified here.

SCIENTIFIC SCOPE
Worked examples use illustrative thresholds and user-defined conservative additive absolute effect bounds, not measurement error estimates or confidence intervals. Negative/positive control requirements apply to the numerical model. An outcome never establishes a physical hypothesis or closes a gate. No independent preregistration timestamp, identities, signature, data collection, real experimental apparatus, statistical power or empirical fit is supplied. Save a sealed file before running and use an independent registry if actual preregistration is needed.
