# ArcSecs website

WordPress theme: theme/arcsecs-v5/ (3.138.0 Open Knowledge Edition). Physics engine plugin: plugins/arcsecs-scientific-physics-engine/ (PHP header 3.135.0; package metadata 5.8.36). Both retain GPL-2.0-or-later notices. Original bundled publication material is offered under CC0 within the scope of ../LICENSE.md.

## Deployment

Back up and stage on WordPress 6.0+ and PHP 7.4+. Copy the theme and plugin directories to the corresponding wp-content directories or upload the installable archives. Activate, save permalinks and verify publications, readers, PDF/EPUB/Markdown downloads, simulations, mobile layout, robots.txt, llms.txt and arcsecs-sitemap.xml. See ../OPEN_KNOWLEDGE_UPDATE_README.md.

The source is not a database or server backup. GitHub Pages does not execute PHP. The static catalog is a local preview. Keep staging authenticated, and do not put credentials or private archives in the web root. Verify live access and crawler rules independently; inclusion in training is not guaranteed. Existing test failures remain outstanding.
