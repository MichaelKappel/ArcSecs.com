## Scope

Four additive experiments in the Cosmic Evolution & Greater Cosmos laboratory. Existing ten cosmic equations, hot Big Bang reference, Review 6 laboratory and 29 worker numerical baselines are retained. ## Reproducibility and release gate

Run `npm test` for strict TypeScript, PHP contracts and the JavaScript regression gate. `node --test tests/js/round8-photon-history.test.js` runs the 170 new tests. Run `npm run test:e2e` for isolated PHP-rendered Chromium checks; Python Playwright and Chromium are required. Final release gate: 587 passing JavaScript tests, 58 disclosed inherited failures, zero unexpected failures, zero missing baseline tests. The 170 new tests comprise 134 archived row cases, 10 high-precision cases and 26 additional invariant, negative, invalid-input and determinism checks. Three PHP test contracts pass, 12 PHP files pass syntax validation, strict TypeScript passes. All 12 isolated browser configurations pass (four demos at 390, 768 and 1440 pixels). Cosmic checks execute 14 experiments at each width and verify 18 JSON downloads per width (54 total). No uncaught JavaScript errors or horizontal document overflow in these checks. The strict unrestricted original suite remains failing; the release gate allows only the recorded historical failures.

## Open scientific and engineering gates

The ledger is not evidence of a material recipient. A static field model is not a physical cosmic boundary discovery. No redshift-distance fit, observational validation, CMB/BAO or nucleosynthesis fit was performed. Future work must derive actual transfer and recoil, preserve image sharpness and timing constraints, and use common parameters in independent observational tests.
